# Website Cahyana — Bakery & Cakes

Website statis responsif untuk usaha kue Cahyana.

## Cara menjalankan di VS Code
1. Ekstrak ZIP.
2. Buka folder `cahyana-kue` di VS Code.
3. Pastikan ekstensi **Live Server** (Ritwick Dey) sudah terpasang.
4. Klik kanan `index.html` → **Open with Live Server**, atau klik **Go Live**.

## Sesuaikan sebelum dipublikasikan
- Ganti `halo@cahyana.example` di `index.html` dengan email usaha yang aktif.
- Sesuaikan produk, foto, harga, alamat, dan tautan pemesanan dengan usaha sebenarnya.
- Foto dari Unsplash dan Google Fonts memerlukan koneksi internet.
- Ini template/prototipe; belum terhubung ke sistem pemesanan atau pembayaran.
